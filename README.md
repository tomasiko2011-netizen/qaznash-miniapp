# QazNash Mini App

Mini app-витрина для Instagram funnel:

- `Landing` — объясняет оффер
- `Demo` — безопасный sample
- `Pricing` — тарифы без trial на живых данных
- `Auth` — мост в Telegram и QazNashBot

## Локально

```bash
npm install
npm run dev
```
